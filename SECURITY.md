# Security policy
 
## Reporting a vulnerability
 
Please do not report security issues in public issues, pull requests or
mailing lists.
 
Report them privately through GitHub's private vulnerability reporting:
open the [Security tab](https://github.com/novnc/noVNC/security) and
click **Report a vulnerability**, or go straight to the
[report form](https://github.com/novnc/noVNC/security/advisories/new).
 
A useful report includes:
 
- the noVNC version, the browser and its version, and the VNC server
  you connect to
- how noVNC is deployed (standalone with websockify, or embedded in another product)
- steps to reproduce, or a proof of concept
- what an attacker can achieve, as far as you know

## What happens next
 
We will acknowledge your report, keep you informed while we work on it, and
agree with you on when to publish. Fixes are released as a new version, and
the issue is described in a GitHub security advisory. We credit reporters in
the advisory unless you prefer not to be named.
 
## Supported versions
 
Security fixes go into the latest release. Older versions do not get
separate fixes; please upgrade.
